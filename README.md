# BMJD 岗位主库

用于完成统一岗位主库、职能分类、岗位JD及来源映射。当前冻结基线 **BMJD-ALL-20261029**：**8,932个岗位、263个职能、2,894个职责系列**。

## 当前进度

- 规则统一已完成，所有活动岗位都有代码和JD草稿；这不代表逐岗专业审定。
- 已收到朋友的5,644岗常规JD回传：5,643岗保留、1岗改写。其余3,288岗JD推定岗位尚未提交，朋友成果尚未整体回填主库。
- Codex负责3,092岗身份推定及全库相邻冲突，尚未产出新一轮整理主库。
- 来源总账19,249条，其中19,226条收录，23条搬运/叉车来源继续暂缓。

最新JD口径：**先看岗位名称，再判断该岗位JD是否匹配；匹配保留，不匹配才重写4—5条。** 不为迁就错贴的JD反向更换已确定名称。名称匹配线索需核实，不能直接当成错误。

## 核验与继续工作

使用Python 3.10或更新版本，核心核验仅需标准库。在仓库根目录运行：

```bash
python tools/project_files.py --check
python JD编写_20261029/schema_check.py
```

核验检查清单及SHA256、主库数量/编码、来源、冻结交接和朋友回传范围，不覆盖JD。build_jd.py会生成并覆盖其输出，阅读或接收已有成果时无需运行。

当前主库和交接输入保持冻结，主库整理及JD接收须建立新版本、保留ID映射和原稿。文件变更后运行python tools/project_files.py --write-manifest刷新清单；新增文件须先加入工具允许列表。
