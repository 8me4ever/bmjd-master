## 核验与继续工作

使用Python 3.10或更新版本，核心核验仅需标准库。在仓库根目录运行：

```bash
python tools/project_files.py --check
python -B tools/specialize_industry_jds.py --check
python -B tools/audit_specialized_industry_jds.py --check
python -B tools/split_industry_masters.py --check
python -B tools/audit_industry_masters.py --check
python -B tools/review_job_jds.py --check
python -B tools/audit_job_jds.py --check
python JD编写_20261029/schema_check.py
python -B tools/audit_job_codes.py --check
python -B tools/unify_all_names.py --check
python -B -m unittest discover -s tools -p 'test_unify_all_names.py' -v
python -B tools/name_code_master.py --check
python -B -m unittest discover -s tools -p 'test_name_code_master.py' -v
python -B tools/advance_master.py --check
python -B -m unittest discover -s tools -p 'test_advance_master.py' -v
```

文件清单核验检查SHA256、名码、来源和历史交接；JD内容与导出另由当前独立核验工具检查。build_jd.py会生成并覆盖其输出，阅读或接收已有成果时无需运行。

当前交付主库和历史交接输入保持冻结，后续整理及JD修订须建立新版本、保留ID映射和原稿。文件变更后运行python tools/project_files.py --write-manifest刷新清单；新增文件须先加入工具允许列表。
