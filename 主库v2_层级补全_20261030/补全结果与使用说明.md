# BMJD主库v2：3—6级岗位补全工作版

版本：BMJD-MASTER-V2-LEVELS-20261030-01。本轮按用户要求“**不修改已有岗位名称，制作新增，参考该序列大致格式**”，只在现有职责系列内新增岗位，保留原版主库作为正式版本。

## 成果和边界

原主库9,111个岗位的全部字段及顺序逐值保持，名称、代码、JD均零修改；原3,077个系列的名称、前四位代码及分类保持。v2新增**2,612岗**，合计**11,723岗**，标准名称、岗位ID与五位岗位代码均唯一。新增全部沿用所在系列四位前缀，代码末位直接采用实际层级，没有新开两位字母段或职责系列。

原3—6级空位共4,104个，逐个形成审查记录；四级齐全的系列由935个增至**2,233个**。仍有1,492个空位，分为：

|处置|数量|含义|
|---|---:|---|
|新增推定岗位|2,612|按同系列称谓和职责补入v2，全部标记待复核|
|同名或别名已有同级岗位|847|其他既有或本轮系列已占用该名称，列出关联岗位，未重复新建|
|名称或别名占用其他层级|73|保留原岗位，不改名或调级，单列待核|
|保留专业边界|572|不适合机械补齐的高管、临床、基础作业、暂缓议题及已知JD错配系列|

“已有同级”仅是名称/别名层面的跨系列线索，不等于职业身份已经合并，也没有把这些空位算成物理补齐。

新增层级分别为3级966岗、4级485岗、5级315岗、6级846岗。

## 命名与JD口径

优先参考本系列既有岗位及其实际层级：职能管理用经理、主管、专员、助理；专业岗位保留工程师、设计师、编辑等称谓，按既有高级/本岗锚点延伸。没有将各类职业统一改为“专员”。先处理层级锚点充分的系列，再审查稀疏系列；遇到名称或旧别名占用，不靠代码、数字级后缀制造另一个岗位身份。

例如薪酬系列缺6级时补“薪酬助理”；专业工程师按该系列现有称谓补足缺级；药学保留副主任/主管药师与药士路线，不套成“药师经理”。厨师不保留“高级初级”双重修饰，驾驶班长不直接用作下一级司机名称。

治理和高管类不虚设初级总经理；临床医生不为填6级新增独立医师；基础作业与驾驶不机械设3级经营岗位。原23条叉车/搬运暂缓来源不恢复，含3条已知旧JD问题的系列不继续扩写错误框架。原岗本身保持原样。

新增JD沿用编号格式，每岗4或5条，以同系列原岗位的专业职责框架及角色层级编写，尽量跨行业通用。初级或辅助岗保留指导/协助边界，药士和护理助理另设辅助职责范围。**所有新增名称及JD均为专业推定，待复核，不宣称来自原表直接新增证据。**

新岗位保留同系列原岗ID、JD参考岗ID、上下文来源清单。新增岗位的`source_ids`为空，原来源仅作为参考上下文。适用行业是同系列范围的推定建议，尚未转换为行业子库成员或行业专业JD。

## 文件使用

先打开[Excel](BMJD主库v2_层级补全.xlsx)的“**仅新增岗位**”工作表，集中审查本次新增；“主库v2全部岗位”包含全量，标明“v1原岗-原样保留”与“v2新增推定-待复核”。另外五张表分别提供缺口、留空原因、全系列、职能统计及规则说明。

- [主库v2.json](主库v2.json)：合并后的完整工作主库。
- [新增岗位候选.json](新增岗位候选.json)：只含新增岗位及其依据；已合入v2，勿再重复导入。
- [逐层级补全审查.json](逐层级补全审查.json)：全部4,104个原空位的处置及关联岗位。
- [职责系列层级审查.json](职责系列层级审查.json)：全部3,077个系列补前补后的层级。
- [独立核验报告](独立核验报告.json)：34项全量数据、备份、唯一性、专业边界及实际Excel检查通过。
- [补全规则](补全规则.json)：显式命名、边界与新增JD规则。

对应TSV分别是全量及仅新增岗位，可按岗位ID追踪；导出中既有岗位的版本列表示所属v2工作稿，原岗位自身的JD版本等字段未被改写。

## 复现与验证

在仓库根目录运行：

```sh
python -B -m unittest discover -s tools -p 'test_complete_master_v2.py' -v
python -B tools/complete_master_v2.py --check
python -B tools/audit_master_v2.py
python -B tools/package_master_v2.py
```

11个规则回归用例通过。`--check`重新计算JSON/TSV并逐字节比较，不改写Excel；独立审查器不导入补全生成器，直接校验实际Excel和全部数据。需重建时执行`python -B tools/complete_master_v2.py`，再依次独立审查、打包。命名梯队与职责适宜性仍属于本次规则和重点案例复核的编辑判断，不将结构检查表述成逐岗原表证实。
