# BMJD内部版与客户版

日期：2026年10月30日。两版共用已确认的9,111岗主库及11行业子库，岗位名称、五位代码、层级和JD不变。

公司内部使用`BMJD内部使用版.html`。发给客户使用`BMJD客户查询版.html`单文件；两份HTML均内置数据，不需要同时发送JSON、Excel或其他文件。双版汇总包用于公司内部保存。

## 功能划分

| 功能 | 内部版 | 客户版 |
|---|---|---|
| 岗位名称、代码、别名与职责搜索 | 保留 | 保留 |
| 行业、职能、专业方向与层级筛选 | 保留 | 保留 |
| 通用与行业岗位JD查看 | 保留 | 保留 |
| 七层岗位矩阵与列表切换 | 保留 | 仅岗位列表 |
| 职责对比 | 保留 | 移除 |
| 我的清单、CSV导出 | 保留 | 移除 |
| 复制代码、JD和对比内容 | 保留 | 移除 |
| 原版分类、原码及编码依据 | 保留 | 移除 |
| 新增岗位入口 | 沿用待同步状态 | 移除 |
| 分页、上一页、下一页 | 移除 | 移除 |

客户版采用独立页面和查询脚本；没有内置清单、导出、复制或对比逻辑，不读取浏览器中的内部岗位清单。客户数据仅保留查询和JD查看需要的字段，不携带原码对照、来源路径或内部审查原因。已知待复核的3个JD仍显示简短职责提示，JD原文没有修改。

## 全部结果在一页显示

初始载入完整9,111岗；内部矩阵一次生成全部3,077个职责方向，列表一次生成全部9,111岗。选定行业、分类或搜索条件后，匹配范围内的所有结果一次显示，通过结果区域滚动查看，没有分页、加载更多或滚动追加。

列表对屏幕外行采用浏览器布局优化，但所有岗位节点已生成；不是只显示第一批或分批取数据。已实际滚动至矩阵和列表末尾打开岗位，确认没有截断。手机默认列表，同样不分页。

内部版的清单使用独立存储键；首次使用时可承接同浏览器中上一版本按岗位ID保存的清单。客户版不读取或保存清单。行业专业JD仍为原843条，所有行业使用已同步子库的当前代码。
