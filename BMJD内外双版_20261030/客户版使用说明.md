# BMJD客户岗位查询

解压后直接打开同目录`BMJD客户查询版.html`，无需联网或额外安装。建议使用近期Chrome或Edge。

1. 先选行业、职能分类及专业方向，也可按名称、代码或常用叫法搜索；要按工作内容查找时切换“同时搜索职责”。
2. 桌面默认“层级对照”：每行一个职责系列，横向依次为1—7级。横线表示未设岗，不代表需要新增岗位。表头参考职级区间用于阅读辅助，不替代岗位价值评估。
3. 点岗位名称查看完整JD；选择行业时显示该行业职责，也可在详情切回通用版。搜索或定位层级后，蓝色为匹配岗位，其余同系列岗位仅作邻级参考。
4. 可切换“岗位列表”。手机默认列表，点“层级对照”可左右滑动看七层矩阵。结果完整显示在同一页，通过结果区滚动查看。
5. 查看JD后点“返回岗位查询”继续查找，或按Esc关闭详情。

本版内置9,111个标准岗位、11行业及843条行业专业JD。版本BMJD-CLIENT-20261030-02；岗位代码、名称及JD与当前确认版本一致。页面仅供查询和职责阅读。
